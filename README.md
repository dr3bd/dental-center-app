# Dental Center App

نظام إدارة مركز أسنان يعمل محليًا (Electron + PWA) لصالح مركز د. عبدالغني البسمي لطب وتقويم الأسنان، مع التزام كامل بمحددات العملة (YER فقط) وغياب أي حقول ضريبية. الواجهة عربية RTL افتراضيًا مع مكونات خفيفة قابلة لإعادة الاستخدام.

## هيكل المستودع

```
apps/
  desktop-electron/   ← غلاف Electron + قدرات النسخ الاحتياطي إلى ملف
  pwa/                ← واجهة Vite + React تعمل كتطبيق ويب تقدمي
packages/
  core/               ← الخدمات، النماذج، قاعدة بيانات محلية بملف JSON مع Seed كامل (sqlite.sql للتصدير)
  ui/                 ← مكونات تصميم RTL قابلة لإعادة الاستخدام
```

## المزايا الرئيسية

- بيانات Seed كاملة (3 أطباء، 20 مريضًا، 10 مواد مخزون مع دفعاتها، 5 مواعيد اليوم، جلسات، فواتير، سندات قبض/دفع، أوامر معامل، مورّدون، Ledger).
- خدمات مشتركة تغطي المرضى، الجلسات، المواعيد، الفواتير، الخزنة، المخزون، المعامل، المورّدين، التقارير، النسخ الاحتياطي، وسجل التدقيق مع حارس مركزي للعملة (YER فقط) ودون أي ضرائب.
- واجهة PWA شاملة لكل الوحدات (لوحة التحكم، المرضى، المواعيد، الجلسات، الفوترة، المخزون، المورّدون، المعامل، الحسابات، التقارير، الإعدادات، سجل التدقيق) مع بحث عالمي (Ctrl/⌘ + K)، تبديل فوري بين العربية والإنجليزية، ووضع مظلم/فاتح قابل للتبديل.
- لوحة أوامر Command Palette (Ctrl/⌘ + K) تقترح تنقلات، مرضى، ومواعيد اليوم مع اختصار سريع لنسخ احتياطي مشفر، إلى جانب بطاقات Dashboard لأعمار الفواتير والمرضى الأكثر نشاطًا.
- مكونات UI جاهزة (DataTable مع بحث/فرز/تصدير CSV+Excel، ChartPanel مع Chart.js، PDFButton يولّد تقارير jsPDF، مخطط أسنان FDI تفاعلي، SmartForm RTL، توستات وإشعارات).
- توليد تقارير PDF عربية جاهزة (سند قبض، سند دفع، فاتورة، أوامر معمل، تقرير دخل شهري) إلى جانب تصدير نسخ احتياطية مشفرة JSON.
- دليل حسابات مهني مع قيد مزدوج كامل (مدين = دائن) يشمل ترحيل تلقائي من الفواتير/السندات/الموردين/المخزون، دفتر أستاذ عام، ميزان مراجعة، قوائم مالية (دخل/مركز مالي/تدفق نقدي)، إقفال شهري/سنوي، وتصدير JSON/Excel للحركات.
- غلاف Electron يوفر تجربة دون اتصال مع تخزين تلقائي في `data/clinic-db.json` وتصدير JSON أو ملف SQL متوافق مع SQLite عبر الجسر المخصص.

## المتطلبات

- Node.js 18+
- npm 9+

## تثبيت الاعتمادات

```bash
npm install
```

## تشغيل PWA (Safari iPad أو المتصفح)

```bash
npm run dev:pwa
```

- يفتح على `http://localhost:4173` مع واجهة RTL.
- يدعم التثبيت كـ PWA (manifest افتراضي Vite) ويمكن العمل دون اتصال بعد التحميل.

## تشغيل تطبيق سطح المكتب (Electron)

```bash
npm run dev:desktop
```

- يشغل خادم Vite للواجهة ثم يفتح نافذة Electron.
- من داخل Electron يمكن طلب `window.backup.export()` (معرّض في preload) لتوليد نسخة JSON مشفرة، أو `window.backup.exportSQLite()` لكتابة ملف SQL متوافق مع SQLite داخل مجلد `backups/`.

## بناء الحزم

```bash
npm run build:pwa      # إنتاج PWA
npm run build:desktop  # يبني PWA ثم يعبئ Electron عبر electron-builder
```

## الاختبارات

```bash
npm test   # يشغّل Vitest على الحزمة core (خدمة المرضى، الجلسات، الخزنة، المخزون، المواعيد، PDF)
npm test -- --run src/tests/e2e.spec.ts   # سيناريوهات E2E للجلسة→فاتورة→سند قبض وتنبيه صلاحية المخزون
```

سيناريوهات مغطاة:
- إنشاء مريض وتوليد كود فريد.
- تدفق جلسة → فاتورة → سند قبض وتحديث حالة الفاتورة تلقائيًا.
- تنبيه صلاحية المخزون خلال ≤ 6 أشهر + خصم الكميات عند ربط المواد بالجسات.
- إعادة جدولة المواعيد وتأثيرها على لوحة التحكم.
- توليد PDF عربي لسند قبض والتأكد من أنه غير فارغ.
- اختبارات E2E: تدفق جلسة → فاتورة → سند قبض مع التحقق من توازن ميزان المراجعة وتنبيه صلاحية المخزون بعد إضافة دفعات جديدة.

## حوكمة البيانات والأمان

- جميع مبالغ *_yer أعداد صحيحة فقط، مع حارس مركزي (ensureYer).
- لا ضرائب/ضريبة قيمة مضافة/تحويل عملة إطلاقًا. أي محاولة لغير YER تُرفض.
- نسخ احتياطي/استعادة JSON مع خيار تشفير AES-256.
- سجل تدقيق Audit Log لكل العمليات الحرجة داخل الخدمات.

## خارطة طريق

- دمج sql.js وDexie لطبقة تخزين PWA طبقًا للـ Repository Pattern.
- تفعيل مزامنة Export/Import مشفرة بين iPad وWindows يدويًا.
- ربط SMS للتذكير بالمواعيد، وتوليد PDF/Excel عبر jsPDF وSheetJS.
